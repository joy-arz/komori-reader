## Install on Android

Download **komori-0.8.15.apk** from Assets below. Android 8.0 or newer. Install over your existing app to preserve your Library, progress and downloads.

## Komori 0.8.15

- Add AsuraScans comics and HiveToons sources, ahead of existing sources in the default tab order. Enable both on fresh installations while retaining existing source-enable and adult-consent choices on upgrade. Asura novels are excluded.
- Support public catalog search, latest/popularity browsing, genres, title metadata, complete chapter lists, reader pages and downloads for the new sources. Asura also supports alphabetical browsing and author/artist catalogs. Preserve locked chapters as unavailable with a source-page link.
- Open downloaded titles with saved metadata and chapters immediately. Offline automatic reading uses complete downloaded chapters; an online refresh no longer blocks starting saved chapters, and failed refreshes keep cached metadata.
- Store downloaded covers outside the evictable image cache and remove them when the title has no downloads left. Library metadata and reading progress remain intact; failed cover requests do not prevent page downloads.
- Turn existing Library categories into visible named library tabs. Create, assign, rename, delete and reorder libraries without deleting titles or downloads. Preserve existing memberships through database migration and retain the order in metadata backups.

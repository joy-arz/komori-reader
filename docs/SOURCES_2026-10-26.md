# October 26 source, search and reader pass

Candidate: 0.8.2. Publication and final CI results are recorded in VALIDATION.md after completion.

## New sources

Manhwa18.com and Manhwa18.cc have separate identifiers, catalog adapters, source origins, verification allowlists and image Referer headers. Source ordering preserves all existing entries and appends the new sources. Custom enabled-source preferences are retained; enable either new source in Settings → Sources if it is absent from Discover.

The .com adapter handles `/tim-kiem`, numeric genre filters, status/sort parameters, background-image covers, both current chapter-list layouts and lazy reader images. The .cc adapter handles `/webtoons`, `/raw`, `/search`, genre routes, source-native catalog sorting, lazy covers and reader images. Korean raw releases retain Korean in title feeds, reading and automatic checks. Neither adapter claims a verified author catalog.

Live inspection and an explicit JVM source test reached both catalogs, details, chapter lists, reader manifests, genre lists and actual image responses. This is point-in-time availability on the tested network, not a guarantee for every device or network.

References: [Manhwa18.com](https://manhwa18.com/), [Manhwa18.cc](https://manhwa18.cc/). Protocol routes/selectors were cross-checked against current site HTML and the upstream [Manhwa18 adapter](https://github.com/keiyoushi/extensions-source/blob/main/src/en/manhwa18/src/eu/kanade/tachiyomi/extension/en/manhwa18/Manhwa18.kt) / [YiiMadara adapter](https://github.com/keiyoushi/extensions-source/blob/main/lib-multisrc/yiimadara/src/eu/kanade/tachiyomi/multisrc/yiimadara/YiiMadara.kt).

## MangaDex and DNS

System resolution of api.mangadex.org and both new sites presented a certificate for internetpositif.id. The redirect certificate was expired; this does not establish that the origin sites' certificates were expired. Encrypted DNS resolution reached the real sites with normal hostname and certificate verification enabled.

Native public-source/CDN requests now resolve through Cloudflare DNS-over-HTTPS, falling back to device DNS when that resolver is unavailable. Browser verification still uses device/browser network configuration. No trust-all certificate manager, permissive hostname verifier or HTTP downgrade is used. Resolver queries disclose requested hostnames to the DNS provider; cookies and Library data are not sent to it.

MangaDex images use the dedicated API transport, a Komori User-Agent and MangaDex Referer. One connection-reset retry uses a fresh HTTP/1.1 pool. The reader and download worker share that path. Empty/missing preferred-quality lists fall back to the available quality. MangaDex HTTP 403 does not suggest an unsupported browser-verification session. True endpoint/IP/network restrictions remain source errors.

The opt-in live test fetched a public MangaDex chapter manifest and an actual image through the new resolver. `KOMORI_NEW_SOURCE_SMOKE=1` enables this test; ordinary CI skips live network checks.

## Search filters

- MangaDex: translated-language availability, original language/origin, publication status, content ratings and tags. Existing safe/suggestive defaults remain. Settings survive saved searches and navigation restoration.
- Manhwa18.com: native genre/category, status and sorting. Korean raw uses the site's Raw genre; English excludes explicitly raw cards from each fetched result page.
- Manhwa18.cc: native language/category/genre catalog routes. Text-search genre/category/status combinations refine the fetched page using title metadata, with at most two concurrent detail requests. Source order or explicitly labelled alphabetical page sorting is offered for text search; native popularity/rating sorting belongs to catalog browsing.
- HentaiZap/ImHentai: title searches keep native language/category filtering; metadata searches can now combine those filters through verified gallery metadata on the fetched page.
- DemonicScans: native genre browsing plus metadata-based genre refinement of title search. English remains its supported reading language. Text-search alphabetical sorting is explicitly page-scoped.
- WeebCentral: existing native text-plus-genre search remains, with its supported English language shown.

Local refinements retain unfiltered pagination identifiers and the native next-page signal. An empty filtered page does not incorrectly prove the catalog has ended. No local refinement claims whole-catalog completeness or globally ranked popularity.

## Reading and downloads

Paged reading records completion when the final page loads. Webtoon reading records completion when the end marker is visible and the final image has loaded. Both end screens offer Read again directly. Explicit reading of a completed collection starts from its first readable chapter; no prior Finish action is required. Historical reread settings remain readable but the redundant toggle is removed.

Downloads remain persisted WorkManager jobs and now run with a data-sync foreground service and an ongoing progress notification. Immediate requests use expedited scheduling with a normal-job quota fallback; delayed retries retain their delays. Opening the notification navigates to Downloads. Normal activity dismissal does not own or cancel the worker. Android Force stop, OS job/service quotas and device power restrictions can still stop or defer work; saved pages and queue recovery remain.

Deterministic instrumentation checks exercise last-page completion/rereading, a MangaDex reset retry during an image transfer after the activity closes, page integrity, image transport headers and the foreground notification contract. Full process-death/slow-network pause/delete stress testing and physical low-memory acceptance remain separate backlog items.
